跡部王国改/ぽにこね式

  • 募集文が「跡部王国改(ぽにこねさん)」なら、MTはTank/Healer表だけ見る。
  • TH/DPS別マクロで行き先候補を4択化。基本は自分のマクロと/echo優先。
  • THの10秒は早ファイガ/ブリザガ、THの30秒は遅ファイガ/ブリザガとして扱う。

水かエラプかの再判断を減らすための補助。X/ロドストのマクロ本文を事前に自分用へ入れておく。

見る順と軽減

  • 自分のデバフを発動順に見る。担当時計は北側に置く意識。
  • 最後はシャドウアイを見ない。戻り先より視線回避優先。
  • リプ担当なら時間圧縮・絶へ入れる。
  • パッセ担当なら詠唱〜着弾に合わせる。
  • 余裕があれば中ファイガ対象へインタベ。

よくあるミスは時計誘導忘れ、時計ビーム、エラプ/ブリザガ、リターン設置、最後の視線。ここでリプを入れない側はシェルクラッシャーへ即リプ。

02:02 アポカリプス安置基準IN見 うちの方針は安置基準。派生元ではなく、安置になった場所を基準にTH/DPSを分ける 安置基 アポ基募集と混同しない。安置2か所と回転方向を先に見る。

安置基準

  • 最初に光らなかった2か所を安置候補として覚える。
  • 光の回転方向を見て、安置になる側へ散開する。
  • TH/DPSの分け方は「安置になった場所のマーカー色」を基準にする。
  • 派生元のアポカリ範囲ではなく、実際の安置を見る。

安置基準は移動距離が少ない。募集文が「アポ基」の時だけ基準が変わるので、今は見ない。

エラプション注意

  • 「安置2か所 + 回転方向」を短く言語化する。
  • スピリットテイカー回避後、円範囲の外側までしっかり離れる。
  • 中央へ入る時に斜め入りしない。
  • エラプ判定は遅め。消えたと思って急がない。

隣とエラプが重なる事故は、初期位置と中央へ入る角度が原因になりやすい。暗夜後はボスを見てTH組左、DPS組右。
02:27 暗夜の舞踏技誘導T MTナイトの山場。誘導後、2連をどちらで受けるか意識 インビン候補 ナイトはP4宵闇よりここでインビン推奨。リプはかなりシビア。

誘導先の見つけ方

  • エラプション3回後、外周2人を結んだ線を底辺にする。
  • 1つだけ横にずれているエラプションを探す。
  • そのずれているエラプションのライン上へ誘導する。

中央集合が甘いと走り出しがシビア。先に誘導先を決めてから動く。

受け方

  • インビン方針なら暗夜本体へインビンを置く。
  • 内側エラプションは2人同時に入らない。必要なら内側がワンテンポ待つ。
  • 暗夜誘導後、2連をどちら側で受けるか先に意識する。

ブラックヘイローをフルバフ、暗夜をインビンにするのがナイトMT向けの基本候補。

遅ファイガ 順番で見る

MTナイト視点では遅ファイガが一番多い。TH4人の2パターン合計で、遅4枠 / 中2枠 / 早1枠 / ブリザガ1枠。

1. 担当を決めるTHは2人なので優先度で2か所へ分かれる。DPSは担当位置固定。

2. 頭割り後に砂時計誘導中央頭割りに入ったあと、自分の担当砂時計の範囲を誘導する。

3. 中央へ戻ってリターン設置2回目頭割り後、中央の模様を目安にリターンを置く。

4. ファイガを外周へ捨てる担当砂時計側の外周へ出てファイガを捨てる。捨てたら中央へ戻る。

5. リターン後は視線を見ないシャドウアイを見ない向きで戻される。余裕があれば反対側で殴る。
